# Architecture and development

Electron main creates the window and registers a narrow preload bridge. The renderer is plain ES modules; engine modules handle link/tracklist import, candidate matching, acquisition, transcoding, tags and destination paths. FFmpeg and yt-dlp are child processes. No server/account/cloud is required in the app.

Install with `npm ci`, `npm run setup:desktop`, and `npm run setup:engine`; run `npm start`. Test engines with `npm test`, the actual desktop with `npm run test:desktop`, synthetic scale with `npm run test:scale`, and package with `npm run dist:portable`. Windows is the supported release platform. CI checks source and packaged desktop workflows plus portable generated-audio export.

Main owns durable track state; renderer session submissions update selection/preferences only. Stable track IDs protect against replacement-queue events; metadata/matching events carry job IDs. Persistence serializes and flushes writes with a last-good backup. Requested metadata and selected recording remain distinct. The ID-scoped preview protocol resolves paths through main state; renderer commands cannot supply preview paths. Audio decisions bind approval to the inspected source hash.

`audioInspection` decodes the entire audio through bounded FFmpeg PCM streaming, stores a compact envelope, and flags possible quiet tails. Metrics are downsampled signal estimates, not mastering certification. `DownloadQueue` pauses flagged tracks, retains review audio, applies only approved endpoints and validates the final MP3. Output sidecars bind recording identity to content hashes. `audioReview` owns waveform/player interactions. The former local-file import and M3U8 export IPC paths were removed in beta 11. Legacy saved local tracks can still use the existing engine path so an older unfinished session is not stranded; no new local imports are offered.

Shutdown waits for an explicit renderer-save acknowledgment, then cancels jobs and flushes durable state (a crashed/unresponsive renderer has a two-second fallback). Approved cached sources are removed only after verified export and real-parent containment checks. On startup, a seven-day sweep removes only unreferenced app-created review directories containing expected source files; saved-session references and unfamiliar contents stay. Session restore holds an operation reservation while it checks finished outputs, propagates cancellation into FFmpeg inspection, and commits the restored queue only after validation finishes. Still to refine: renderer-wide state/render separation, forced-crash/disk fault injection during restore, broader schema coverage, representative matching corpus, and Windows accessibility acceptance. See PROGRESS for exact evidence; none of these should be inferred complete from the current smoke test.

Version policy: keep package.json and package-lock.json aligned; beta increments for reviewable changes, stable only after MASTER_PLAN release gates. Record each checkpoint in CHANGELOG and PROGRESS. Do not merge/publish stable based solely on local tests.
